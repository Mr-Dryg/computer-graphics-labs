# Лабораторная работа по "Компьютерной графике"

## №1. Вариант №6 — Пирамида
## №2 — Камера и освещение

Реализована интерактивная сцена с камерой и освещением по модели Блинна-Фонга.

**Архитектура дескрипторов** (два набора, как требует дополнительное задание 1):

| Набор | Содержимое |
|-------|-----------|
| `set 0` — сцена | uniform `SceneBlock` (view-projection, позиция камеры, ambient, направленный источник, счётчики источников) и storage-буферы `PointLightBlock` / `SpotLightBlock` с массивами источников |
| `set 1` — модель | uniform `ModelBlock` (матрица трансформации, матрица нормалей, альбедо, цвет и коэффициент блика), доступ к отдельному объекту — через динамическое смещение в общем буфере |

Число элементов в массивах источников не задано константой в шейдере: буферы
storage позволяют менять их количество без перекомпиляции шейдеров.

**Типы источников света:**

- *Направленный* — без затухания, задаётся азимутом и тангажом.
- *Точечный* — затухание по закону обратных квадратов с мягким срезом у границы радиуса действия.
- *Прожекторный* — затухание по закону обратных квадратов, конус с мягкими краями: интенсивность плавно нарастает между внешним и внутренним углом.

**Нормали** генерируются процедурно из положения вершин при построении
геометрии: `cross(v0 - v1, v2 - v1)`.

**Управление** (ImGUI):

- Панель «Камера» — позиция, азимут, тангаж, угол обзора. ЛКМ + мышь вращает
  камеру, колесо меняет угол обзора, `W/A/S/D` перемещают, `Q/E` поднимают и
  опускают.
- Панель «Сцена» — ambient, направленный источник, материалы пирамиды и пола
  (альбедо, цвет блика, коэффициент блика), трансформация объекта и анимация.
- Панель «Источники света» — добавление и удаление точечных и прожекторных
  источников, изменение их параметров, прикрепление к пирамиде и показ
  визуализации.

**Визуализация источников** — куб цвета источника для точечного, куб и
полупрозрачный конус для прожекторного. Фигуры имеют постоянный цвет и не
освещаются по модели Блинна-Фонга.

### Заметка об отражении оси Y

В Vulkan ось Y в NDC направлена вниз, поэтому изображение отражается. Отражение
выполняется в матрице проекции, а не в матрице вида: у проекции в строке Y всего
одно ненулевое значение, поэтому знак меняется у всей строки разом. Отражение
одного элемента матрицы вида при наклонной камере искажает базис вида и ломает
winding у части граней — они отсекаются поодиночке.

## Конфигурация

```bash
cmake --preset debug       # for GNU/Linux (GCC/Clang)
cmake --preset msvc-debug  # for Windows (Visual Studio 2026)
cmake --preset mingw-debug # for Windows (MinGW)
```

## Сборка

```bash
cmake --build build-debug --parallel # for debug
cmake --build build-release --parallel # for release
```
